# 凑一局总站

[fonjure.github.io](https://fonjure.github.io/) 是凑一局的固定入口。它分别检测三个游戏入口的公开连接状态，优先推荐可用的正式入口，必要时推荐响应更快的备用入口，也可手动选择；另保留作者疯不觉的小红书名片。页面不会自动跳转；旧域名的提示页引导玩家回到本站，避免更换服务器后收藏失效。

当前[正式入口为 couyiju.xyz](https://couyiju.xyz/)，备用入口一为 [sslip.io 地址](https://couyiju.47-76-72-151.sslip.io/)，备用入口二为[原香港域名](https://hk.couyiju-fonjure.dns.army/)。三个域名通向同一台香港服务器，账号、好友和战绩使用原有数据；入口冗余不等于服务器或数据库备份。浏览器按网站来源保存登录状态，切换入口需要重新登录，游客凭据不会自动带过去。游戏源码与部署流程保存在另一个私有仓库 `Fonjure/couyiju`；此公开仓库只有门户静态文件，不含游戏源码、题库、账号、会话、记录、密钥或数据库。

## 文件结构

- `index.html`：门户页面，默认提供可点击的服务器入口；不依赖 JavaScript 也能手动进入游戏。
- `404.html`：与首页相同的门户，支持从旧的深路径邀请进入；修改门户后应同步此文件。
- `assets/site.css`：无外部依赖的响应式样式，米白背景、简洁排版，兼容手机。
- `assets/site.js`：读取公开配置，并行检查三个入口的 `/health`，推荐与手动选择入口、手动重试及复制小红书号。不会连接游戏 WebSocket 或调用账号、会话接口，不写浏览器账号存储，也不持久化入口选择。
- `assets/xiaohongshu.jpg`：用户提供的小红书名片原图，按原字节复制。不要裁剪、重绘、压缩或重新生成二维码；页面可打开原图和保存图片。小红书号为 `841618732`。
- `site-config.json`：公开的服务器与维护配置；**不要放任何密码、API Token、SSH 密钥或个人游戏数据**。
- `.nojekyll`：让 GitHub Pages 直接发布静态文件。

## 服务器与维护配置

一般换服或维护只需编辑 `site-config.json`：

```json
{
  "serverOrigin": "https://couyiju.xyz",
  "serverName": "香港服务器",
  "preferredEntry": "xyz",
  "entries": [
    { "id": "xyz", "name": "正式入口", "origin": "https://couyiju.xyz" },
    { "id": "sslip", "name": "备用入口一", "origin": "https://couyiju.47-76-72-151.sslip.io" },
    { "id": "hk", "name": "备用入口二", "origin": "https://hk.couyiju-fonjure.dns.army" }
  ],
  "maintenance": false,
  "maintenanceMessage": "服务器正在维护，请稍后再来。"
}
```

`entries` 目前使用与页面对应的 `xyz`、`sslip`、`hk` 三个入口 ID；每项的 `origin` 必须是 HTTPS 纯来源地址，不含用户名、密码、路径、查询参数或片段，末尾斜杠可省略。入口域名可更换，无需改变入口 ID。无效的单个入口会被跳过，不影响其他有效入口；全部无效或配置读取失败时使用脚本内置的三个入口。保留的 `serverOrigin` 兼容旧配置：未提供 `entries` 时作为正式入口，另补充内置备用地址；同一来源只保留一次。

`preferredEntry` 指定默认优先的入口 ID，当前为 `xyz`。该入口健康时始终推荐它，即使备用入口响应更快；它不可用、维护中或尚未返回健康结果时，推荐已健康的备用入口中本次耗时较小者。若配置没有首选 ID 或指定了无法识别的值，使用内置首选 `xyz`；首选未包含在有效入口中时仍可正常推荐其他健康入口。

`serverName`、入口 `name`、`maintenanceMessage` 是可选展示文案；可额外保留 `updatedAt` 供维护者记录更新时间，页面不依赖它。`maintenance` 只有布尔值 `true` 表示全局主动维护，此时不请求健康接口，并暂停全部入口；恢复为 `false` 后重新检测。若只有某入口的健康响应明确声明维护，仅暂停该入口，另一入口仍可使用。

更换入口还需要同步 `index.html`、`404.html` 的默认链接和 `assets/site.js` 的 `DEFAULT_ENTRIES`，供 JavaScript 加载失败、配置不可读或禁用脚本时使用。禁用 JavaScript 时显示三个直接访问链接，主按钮默认指向正式入口。新后端必须允许来自 `https://fonjure.github.io` 的 CORS 健康检查。门户不需要后端密钥，也不应携带玩家 Authorization 或 Cookie。

进入按钮保留原来的路径、查询参数和 URL 片段，例如 `/?room=ABC123#join` 会带到所配置服务器。`/index.html`、`/404.html` 自身会归一为服务器首页。查询参数里的 `next` 等值不会改变目标来源，因此不构成开放重定向。

## 状态含义

正常与检测中的界面只显示状态点和简短文字，随后直接展示入口、指标和进入按钮。维护或连接异常时显示对应说明；更新时间仅显示时间与“更新”，检测期间显示“检测中”。

打开页面时检测一次，也可点击“重新检测”；不会持续轮询。公开配置读取最多约 2.5 秒，之后各入口独立以 7 秒上限并行检测，不使用浏览器请求缓存。默认选择正式入口；首个健康备用入口返回后也可立即推荐并进入，不必等正式入口超时，正式入口随后恢复健康时自动推荐正式入口。正式入口失败或维护时从健康备用中选本次耗时较小者。手动选择优先于自动推荐，检测完成或重新检测不会覆盖仍有效的手动选择；推荐徽标仍随检测结果更新。

- **能连上 / 连接顺畅**：该入口 HTTP 成功，且 JSON 中 `service=couyiju-server`、`protocol=1`、`runtime=node`，`status`、`storage`、`database`、`rooms` 均为 `ok`。
- **维护中**：本站全局维护开关开启时全部按钮暂停使用；单入口健康响应明确包含 `maintenance: true` / `status: maintenance` 时只暂停该入口。已手动选择的入口后来报告维护时，主按钮暂停，用户仍可选择另一入口。
- **服务暂不可用**：服务器已返回 HTTP 错误（包括没有明确维护声明的 503），或正确的 Node 健康响应表明组件暂未恢复。不能据此宣称正在计划维护。
- **暂时没连上**：网络、超时、CORS 或无法识别健康响应。它只表示当前访问者无法确认该入口状态，**不等于全服维护**，也不能据此断言需要代理；即使全部入口都失败，仍可手动选择并尝试进入游戏。

健康状态只反映本次检查，不保证之后的每一次游戏连接成功。本站不检测或修改访问者的代理设置。

健康检查成功时附带所选入口的三项概况：`memory.rssBytes` 为游戏服务进程的物理内存占用（不是整台服务器使用量），`uptimeSeconds` 为该进程运行时长，发布或重启后重新计时；访问耗时由当前浏览器测量该入口 `/health` 请求至响应读取完成的时间，受本地网络、连接和服务器响应影响，不代表下载带宽。内存和时长字段缺失时显示 `—`，切换到检测中、失败或维护的入口时清除概况，避免把旧数值当成实时状态。这里只请求公开 `/health`，不读取管理员后台数据。

## 编辑、预览和发布

这是独立的公开仓库 `Fonjure/Fonjure.github.io`，仅发布 `main` 分支根目录，不能把私有游戏仓库覆盖推送到这里。没有 npm 构建、CDN 字体、跟踪脚本或 Sites 项目依赖。

Windows PowerShell 中可用已安装的静态 HTTP 服务预览此目录；不要直接用 `file://`，否则浏览器无法读取配置。预览时的健康请求来源是本地地址，真实香港后端可能拒绝本地 CORS；可用浏览器测试拦截公开 `/health`，不要为预览临时开放生产账号接口。

浏览器回归需要安装 Chrome 与 `@playwright/test`；可用环境变量 `PLAYWRIGHT_MODULE` 指定已有模块的路径，再运行 `node --test test/entry-selection.test.cjs`。测试使用本地页面与拦截的健康响应，不创建生产账号或房间。

发布前检查 JSON、脚本语法、手机布局、无 JavaScript 回退、健康/维护/连接失败状态和邀请链接保留。将所需文件提交并推送到本仓库 `main`，等待 GitHub Pages 部署成功；再检查线上总站没有自动跳走、图片与手动进入按钮正常。

小红书名片替换时应保留原始二维码。更新 HTML/CSS/JS 后，必要时递增 HTML 中的静态资源版本（当前 `?v=portal-7`）；`404.html` 与 `index.html` 保持一致。
